**APEX-QC** is a cutting-edge Agentic AI platform designed to handle complex, real-time incidents in the Quick Commerce (QC) ecosystem. By utilizing **Amazon Nova** via **Amazon Bedrock**, APEX-QC coordinates a network of specialized AI agents to resolve delivery conflicts, reroute resources, and optimize pricing dynamically during major disruptions.

## 🚀 Key Features

- **Multi-Agent Orchestration:** A central orchestrator that manages specialized agents for Logistics, Pricing, and Customer Success.
- **Real-Time Incident Resolution:** Automated handling of high-impact events like sudden weather shifts, traffic surges, or localized supply drops.
- **Advanced Reasoning:** Powered by **Amazon Nova Pro**, enabling multi-step decision making and complex conflict resolution.
- **Actionable Outputs:** AI-driven decisions are fused into executable operations (e.g., dynamic rerouting, incentive adjustments, real-time alerts).
- **Safety & Guardrails:** Built-in confidence scoring and impact assessments to ensure reliable automated operations.

## 🛠️ Tech Stack

- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS.
- **Backend:** Node.js, Express.
- **AI/ML:** Amazon Bedrock (Amazon Nova Models), Agentic Reasoning Loops.

## 📦 Getting Started

### Prerequisites
- Node.js (v18+)
- AWS Account with Bedrock access (if using real reasoning models).

### Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/2k33cse992574/apex-qc.git
   cd apex-qc
   ```

2. **Backend Configuration:**
   Navigate to the backend and install dependencies:
   ```bash
   cd backend
   npm install
   ```
   *To use Amazon Nova reasoning, configure your AWS credentials in the environment.*

3. **Frontend Configuration:**
   Install dependencies and start the development server:
   ```bash
   npm install
   npm run dev
   ```

4. **Execution:**
   - Start the backend: `npm run backend`
   - Open your browser to the local dev port.
   - Use the **Dashboard** to trigger simulated incidents (e.g., "IPL Night Mumbai") to witness the full orchestrator flow.
